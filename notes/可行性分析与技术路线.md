# 可行性分析与技术路线

> 选题：融合单细胞转录组表达特征与细胞邻域图结构的细胞类型注释可靠性评估模型
> 结论：**思路可行，方向正当其时，但需要收敛范围、收紧"可靠性"的定义与评估体系。**

## 一、可行性判断

### 1. 选题角度成立，且踩在领域热点上

"注释可靠性评估"（uncertainty quantification / 开集识别）是 2023–2025 年该领域的明确趋势：

| 相关工作 | 时间 | 与本课题的关系 |
|---|---|---|
| CHETAH / scLearn / scHPL | 2019–2021 | 带"拒绝选项（unassigned）"的经典基线 |
| scGAD | 2023 (Briefings in Bioinformatics) | 开集场景下注释+新细胞发现 |
| MiCAS | 2024 (preprint) | 高斯混合模型做开集识别，与你的 GMM 创新点直接相关 |
| Uncertainty Quantification for Atlas-Level Cell Type Transfer | 2024 | 用 DKL/MIMO 做不确定性量化，强调校准（ECE） |
| Conformal inference for reliable scRNA-seq annotation | 2025 (Bioinformatics) | 用 conformal prediction 给出有统计保证的预测集合 |
| CASSIA | 2025 (Nature Communications) | LLM 多智能体注释+质量评分 |

**启示**："给注释一个可信的置信度"这个问题真实存在且被反复确认——强制标签（forced label）是参考映射类方法的结构性缺陷。你的切入点（融合表达特征 + 邻域图结构做可靠性评估）在这些工作中**没有被直接占满**：conformal 那条线不做图结构，GNN 那条线（scGCN/scDeepSort）不做校准的可靠性。空间是有的。

### 2. 技术组件全部有文献支撑，拼装逻辑自洽

思路总结里列的 14 项技术，每一项都能对应到已读文献的方法，且已有论文（石永乐 scADCA/scZLCA、孙熠伟 ScLabler、蒋英 sc-ImmuCC 等）证明其在本科/硕士课题体量下可复现、可改进。

### 3. 数据与评估方案基本现成

GSE128982、GSE109774、GSE159929、HRA000150 四个数据集在康其传的工作中已经跑通；评估维度（跨组织、跨物种、模型对比）有 Abdelaal 2019 和 Luecken 2022 两大 benchmark 做参照系。

## 二、主要风险（必须解决）

1. **范围过大**。思路总结里同时有：分层注释、稀疏模型、卷积、LIME、重构误差、ZINB、ScoRR、γ模型、Gene2Vec、PCC、Longformer、标签基因损失、SMOTE、GAT——这是三篇硕士论文的量。本科毕业论文做 1 条主线 + 2~3 个辅助模块就够了。
2. **"可靠性"缺少可操作的定义**。目前的评估指标（ACC、F1、漏检率）衡量的是"注释准不准"，不是"可靠性评估准不准"。可靠性模型必须新增：
   - **校准误差 ECE**（置信度和实际准确率是否匹配）
   - **OOD/新细胞检测的 AUROC、AUPR**
   - **风险-覆盖率曲线（risk-coverage / accuracy-rejection curve）**——这是可靠性论文的标准图
3. **创新点 4 和 6 偏散**。GMM 和 LOF 是手段不是创新点，应该统一进"可靠性评估"这条主线（见技术路线）。
4. **缺少对 conformal prediction 的回应**。2025 年那篇 Bioinformatics 论文之后，做"可靠性"不提 conformal 会在答辩时被问。建议把它作为校准层的可选组件或至少作为对比基线。

## 三、建议的技术路线

### 总体架构（一条主线、三个阶段）

```
原始 scRNA-seq 数据
   │
   ▼
[阶段0] 数据预处理 ─────────────────────────────
   质控 / 归一化 / HVG 选择（陈锐朴流程）
   MMD 映射消除批次效应（刘岩 scMDR 思路）
   │
   ▼
[阶段1] 双通道特征提取 ─────────────────────────
   通道A（表达特征）：
     "主题"算法（LDA/NMF 式基因模块，陈和港）
     可选：ZINB 或 GMM 建模 dropout/双峰（石永乐、赵舒畅）
   通道B（图结构特征）：
     KNN/SNN 构图 → GAT 编码器聚合邻域信息（孙熠伟）
   融合：主题向量 ⊕ 图嵌入 → 拼接/门控融合
   │
   ▼
[阶段2] 注释 + 可靠性评估（核心创新）──────────
   分类头：已知类型分类（含标签基因损失，谢青松；SMOTE 处理不平衡，孙熠伟）
   可靠性三视角打分：
     ① 分类置信度：softmax 熵 / top-1 top-2 margin
     ② 图一致性：KNN 邻域标签一致率、GAT 注意力熵 ← 选题的"图结构"落点
     ③ 异常度：ZINB 自编码器重构误差 + LOF 局部密度（石永乐）→ 识别新细胞
   融合为可靠性分数 → 低于阈值判 unassigned
   （可选增强）conformal prediction 校准，输出带统计保证的预测集合
   自校正：高可信锚点细胞迭代修正低可信标签（何永歆 ScoRR）
   │
   ▼
[阶段3] 评估 ───────────────────────────────────
   基础指标：ACC、macro-F1、漏检率、运行时间
   可靠性指标：ECE、OOD 检测 AUROC/AUPR、risk-coverage 曲线
   维度：同数据集 / 跨批次 / 跨组织 / 跨物种
   对比基线：SingleR、CellTypist、CHETAH、scLearn、scHPL、scANVI（+conformal）
   消融：图通道开关 / 主题通道开关 / 各可靠性分量开关 / SMOTE / MMD
```

### 模块取舍建议（从思路总结中收敛）

| 思路总结条目 | 建议 |
|---|---|
| MMD 批次消除 | ✅ 保留（阶段0） |
| "主题"算法表达特征 | ✅ 保留（主线通道A） |
| GAT/KNN 邻域图 | ✅ 保留（主线通道B + 可靠性视角②） |
| ZINB 重构误差 + LOF 识别新细胞 | ✅ 保留（可靠性视角③，与石永乐区分：你是"双通道一致性"判定） |
| ScoRR 自校正 | ✅ 保留（阶段2 末尾，工作量小、故事好讲） |
| 分层注释（蒋英/谢青松） | ⚠️ 降为可选：只在免疫细胞子任务上演示一层，不作为主线 |
| SMOTE | ⚠️ 保留但降级为预处理技巧，写进消融 |
| LIME 可解释性 | ⚠️ 可选加分项：最后给"哪些基因/邻居导致低可信度"的解释 |
| 稀疏模型、卷积、γ模型、Gene2Vec、PCC、Longformer | ❌ 砍掉。它们各自成立但拼进主线会让论文失焦 |

### 创新点重新表述（建议）

1. **双视角可靠性评估**：首次将"表达空间置信度"与"细胞邻域图一致性"联合建模为注释可靠性分数（现有 GNN 注释方法不做校准，校准方法不用图结构）。
2. **重构误差 × 局部密度双通道新细胞识别**：ZINB 重构误差捕获全局表达异常，LOF 捕获局部邻域异常，二者一致性判定降低误报。
3. **自校正闭环**：高可信锚点反向修正低可信细胞标签，可靠性分数既是输出也是迭代信号。

### 实验与里程碑（按本科毕设节奏）

1. **第 1–2 周**：复现数据预处理流水线（陈锐朴流程），四个数据集统一为 h5ad；跑通 SingleR/CellTypist 基线。
2. **第 3–5 周**：实现通道A（主题特征）+ 通道B（KNN-GAT），先只做注释不做可靠性，确认 F1 不掉队。
3. **第 6–8 周**：实现可靠性三视角 + 阈值拒绝机制；在"留一细胞类型"（hold-out one cell type）开集协议下调参。
4. **第 9–10 周**：ScoRR 自校正 + （可选）conformal 校准层。
5. **第 11–13 周**：完整评估（跨组织/跨物种/基线对比/消融），画图（risk-coverage、ECE 校准曲线、UMAP 标注可靠性热力）。
6. **第 14 周起**：写论文。LIME 解释性分析作为最后一节实验加分。

## 四、一句话总结

**可行，且方向正确；把 14 个技术点收敛成"双通道特征 → 三视角可靠性打分 → 自校正闭环"这一条主线，并补上 ECE / AUROC / risk-coverage 这套可靠性专用评估，这个课题就立得住。**
